# ML Examples

This repository contains a collection of examples of machine learning (ML) applied to weather, climate and Earth sciences for the purposes of education and training, created and curated by [ECWMF](https://www.ecmwf.int/).

View these examples in a book:

:notebook: :point_right: https://ecmwf-training.github.io/ml-examples/ :point_left: :notebook:

The book also contains details of how to run these examples.
